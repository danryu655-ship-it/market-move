# Market Move

Dashboard arah harga crypto — 18 koin (BTC, ETH, BNB, ENA, ONDO, XAU/PAXG, SHIB, PENGU, SUI, XPL, PUMP, PYTH, ZEC, ASTER, JUP, HYPE, WCT, SOMI).

- Data live langsung dari Binance Spot public API (tanpa API key), dihitung di browser: RSI 14, EMA20/EMA50, ATR 14, volatilitas 1 jam, forecast high/low, support/resistance 1 jam & 6 jam, skor Bias Momentum.
- Auto-refresh tiap 60 detik + jam "Terakhir diperbarui" (WIB).
- Seksi Pemantau Crypto Live: snapshot terakhir dari monitor sinyal (GeckoTerminal new-pool momentum) — bukan data live.

Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → Deploy from branch, folder `/ (root)`).
